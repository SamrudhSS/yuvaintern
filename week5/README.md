# Week 5 — Model Evaluation and Reporting Strategy

**Dates:** 19–26 November 2026 · **Status:** ⬜ Not started

## Task

Develop a strategy for evaluating a predictive model and communicating the findings: performance
metrics, visualisation of results, an executive summary of performance with recommendations, and a
discussion of limitations and further refinement.

## Planned content

- Metric set and when each one misleads: RMSE, MAE, MAPE and its near-zero problem, MASE, R², pinball
  loss, interval coverage, directional accuracy, bias.
- Evaluation design: rolling-origin backtests, reporting by crop, state and horizon rather than one
  pooled number.
- Visualisation for non-specialist readers: predicted versus actual, error by horizon, interval
  coverage bands, residual diagnostics, scenario fan charts.
- Executive summary template: the finding, the range, the decision, the caveat.
- Limitations: coverage bias in mandi data, publication lag, policy breaks, short series, transfer to
  unobserved crops.
- Refinement roadmap: additional indicators, longer history, higher-frequency data, alternative models.
