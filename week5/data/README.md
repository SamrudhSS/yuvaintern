# Week 5 — Executed Evaluation Data

All files in this folder are generated by `week5/_build/evaluation_engine.py` from the real
World Bank Pink Sheet monthly commodity series prepared in Week 4. Nothing here is simulated or
hand-entered.

## Source and window

| Item | Setting |
|---|---|
| Source | `week4/data/world_bank_agricultural_benchmarks_2000_2026.csv` |
| Original series | World Bank Commodity Markets Outlook, Pink Sheet, November 2026 edition |
| Window | 2000-01 to 2026-10 (322 monthly observations) |
| Design matrix | 310 usable months × 31 predictors |
| Primary crop | Wheat, US HRW, USD/metric tonne |
| Cross-check crops | Rice, maize, soybeans, cotton |
| Primary folds | 60 expanding-window origins, 3-month step, minimum 120 training months |
| Horizons | 1, 3, 6 and 12 months |
| Models | Random walk, seasonal naïve, ETS, SARIMAX, direct GBDT, inverse-MSE ensemble |
| Forecast rows | 1,440 (60 folds × 4 horizons × 6 models), zero model failures |
| Audit runtime | 591 seconds on the build laptop |

The exact source file is also used by the Week 4 notebook. Week 5 reproduces the Week 4
ensemble MAE to 0.000% at every horizon and then extends the audit.

## Files

| File | Contents |
|---|---|
| `fold_predictions_wheat.csv` | Primary 60-fold, four-horizon, six-model fold-level forecasts with online conformal bands |
| `fold_predictions_wheat_primary.csv` | Byte-identical copy of the primary wheat file, kept for explicit naming in rebuild scripts |
| `fold_predictions_cross_*.csv` | 45-fold cross-commodity predictions for rice, maize, soybeans and cotton |
| `metrics_by_horizon.csv` | 24 scored rows: six models × four horizons, 27 metric fields |
| `metrics_by_commodity.csv` | The same metric suite for all five crops at every horizon |
| `calibration.csv` | Nominal versus empirical coverage at 50%, 80%, 90% and 95% |
| `significance.csv` | Paired bootstrap 95% intervals, Diebold–Mariano statistics and minimum detectable effects |
| `regime_metrics.csv` | MASE before and after January 2023, by horizon and candidate |
| `volatility_metrics.csv` | MASE by low, mid and high volatility tercile at the forecast origin |
| `decision_curve.csv` | Procurement cost, regret, hit rate and rise capture across a −3% to +6% threshold grid |
| `latest_forecast.csv` | The October 2026 origin forecast for all four horizons, with conformal bands |
| `folds.csv` | Fold number, origin, training length and target dates |
| `final_weights.csv` | Ensemble member weights at each horizon, estimated from past-only inverse MSE |
| `facts.json` | Machine-readable fact base consumed by the report builder; the prose is generated from this file |

## Reproducing

From the repository root:

```powershell
python week5\_build\evaluation_engine.py
python week5\_build\diagram_generator.py
python week5\_build\build_week5.py
powershell -ExecutionPolicy Bypass -File week5\_build\export_pdf.ps1
python week5\_build\scrub_metadata.py all
```

The engine is deterministic: the random seed is fixed at 42, the ladder is not tuned per fold,
and the final-origin forecast uses the same specification as the backtest.

## Metric conventions

- **MASE vs RW** is the primary promotion metric: candidate MAE divided by random-walk MAE on
  the same folds and horizon. Below 1.0 beats the benchmark.
- **MASE (absolute)** divides by the mean absolute first difference over the first 120 months.
  It is reported for comparability with the literature but is not the gate.
- **Coverage** uses the 52 folds with an issued conformal interval; the first eight folds have no
  prior residual pool.
- **Directional accuracy** compares the sign of the forecast change with the sign of the realised
  change from the origin price. A random walk has no direction and is excluded from that table.
- **CWE** uses a 4:1 asymmetry: a shortfall costs 1.00 and an excess costs 0.25.

A failure is retained in the data, not deleted. The model that loses at h=3 is still in
`metrics_by_horizon.csv` and in the cross-commodity scorecard.
