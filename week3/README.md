# Week 3 — Exploratory Data Analysis (EDA) Report Design

**Dates:** 5–11 November 2026 · **Status:** ⬜ Not started

## Task

Design a complete outline for an EDA report on agribusiness trends: the variables and metrics that
matter, the visualisations appropriate to each, the report sections, and how anomalies and correlated
features will be handled.

## Planned content

- Variable inventory: production, area, yield, arrivals, modal and real prices, rainfall departure,
  vegetation anomaly, fertiliser intensity, stocks, trade.
- Analysis types: distribution and coverage, seasonality (STL), lead–lag relationships, state
  comparison, price dispersion, correlation structure.
- Visualisation plan mapped to question type — small multiples for state comparison, seasonal
  decomposition for prices, scatter with fitted trend for yield drivers, heat-maps for correlation.
- Report sections: executive summary, data and methodology, findings by lens, anomalies, implications,
  limitations.
- Anomaly protocol and correlation handling, including why correlation is not a driver and how to test
  stability across sub-periods.
